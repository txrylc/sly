扫雷一下

一个 HTML 文件装下的完整扫雷世界 · 创作者：张帆（北京） · gitee.com/xuexiaosuomen

一、这是什么

「扫雷一下」是一款纯单文件扫雷：整个游戏——界面、逻辑、录像系统、防作弊体系——全部装在一个 minesweeper.html 里，无需联网、无需安装、无任何外部依赖，浏览器双击打开即玩。它不是"又一个扫雷网页"，而是一套对标国际扫雷竞速标准的完整工具链。

二、软件架构

minesweeper.html（单文件 · 全内联 · 零依赖） ├─ <style> 全部界面样式（经典皮肤/配色/字体可切换） ├─ <body> 全部界面结构（棋盘/设置/记录/绘图/关于） └─ <script> IIFE 闭包 + 'use strict' ├─ 防篡改层 SHA-256 指纹 + RSA-2048 构建签名 · 加密难度表 · 原生函数固化 │ defineProperty 关键属性守卫 · 定时巡检 · DevTools 拦截 ├─ Minesweeper 类（prototype 已冻结） │ ├─ 输入层 鼠标状态机（左弹揭示/右按标旗/双弹合击）· 空格/中键重开 │ ├─ 逻辑层 布雷 · 洪泛揭示 · 标旗 · 合击 · 胜负判定 │ ├─ 统计层 3BV/空数/数数 · iOS/IOE/RQP/QG/FRM/s/完成率 · 0.1s 采样 │ └─ 录像层 actions + mouseTrail + statsSeries 三轨记录 │ ↓ gzip 压缩 + AES-GCM 加密（指纹派生密钥） │ .sly 二进制文件导入导出 · IndexedDB 本地存档 └─ 回放引擎 逐帧复现操作与鼠标轨迹 · 进度条 · 过程参数八线绘图

三、对扫雷传统的继承

  • 经典手感：左键弹起揭示、右键按下标旗、左右双键弹起合击——严格还原老玩家肌肉记忆的输入状态机；格子凹凸质感、数字 1~8 经典配色原汁原味。
  • 经典规则：首击必安全（可选"第一击可不为空"）、失败亮出全部雷、双击数字快速开格、胜利后计时定格。
  • 经典度量：完整实现 3BV（空数 + 数数）计算——8 连通成片空格为空数，不与空格 8 邻接的数字格为数数，口径与国际社区一致。

四、与国际接轨

内置国际扫雷竞速社区（minesweeper.info 排名体系）使用的全套参数，实时计算、随录像存档：

参数含义
3BV完成局面所需的最少点击数；本作同时提供总3BV与当前3BV（已完成3BV）双口径
3BV/s每秒完成的 3BV，竞速核心指标
iOS / IOE速度指数 / 效率指数：iOS = ln(用时)÷ln(3BV)；IOE = 3BV ÷ 总点击数（含无效点击）
RQP / QG时间与 3BV 的比值衍生指标（QG = Time1.7÷3BV）
FRM/s每秒"八邻域非雷格已全部打开"的雷数（本作首创）
完成率（已揭示非雷格占比 + 全开雷占比）÷ 2 的综合完成度；LC/MB 残局判定与国际习惯一致

计时精确到 0.1 秒（记录与录像中保留 3 位小数），风格自动判定（盲扫/几乎不标雷/部分标雷/全标雷）。

五、现代新功能

四项创新

  • 当前3BV（已完成3BV）：传统扫雷只给一个固定的总3BV，本作额外实时计算"达到当前已揭示局面所需的最少点击数"——它只从已完成（已揭示）的部分推导，完全不涉及任何未揭示部分，随扫随涨、直观反映推进量；并以它替代总3BV作为终局与录像回放的指标口径——推进不足的一局不会被虚高的总3BV美化成绩，这让过程与终局指标第一次真正"可读"。
  • 完成率：由"已揭示非雷格占比"与"八邻域全开的雷占比"各占一半合成的综合完成度，同时覆盖盘面推进与雷区清理两个维度；失败局给出确切进度与 LC/MB 残局判定，把"差多少"量化出来。
  • FRM/s：本作首创提出的新指标（Fully Revealed Mines）：周围八邻域非雷格已全部打开的雷数 ÷ 用时，衡量扫雷中盘清理雷区的效率；对局中不直接显示，避免泄露未探明雷的邻雷信息。
  • 过程参数绘图：当前3BV、完成率、3BV/s、iOS、IOE、RQP、QG、FRM/s 八条曲线可勾选显隐，一图看出整局节奏起伏，失败局也能复盘在哪一步掉速。

全程录像与回放

  • 每一局自动记录 操作序列 + 鼠标轨迹 + 参数采样 三条轨道，回放时逐帧复现，带进度条与已用/总时长。
  • 录像经 gzip 压缩 + AES-GCM 加密存为 .sly 文件，可导出分享、导入观看；加密密钥由代码指纹派生，录像与游戏版本互相校验——只支持当前版本，不兼容旧版本录像。
  • 拖拽即看：把 .sly 录像文件直接拖到页面上就能播放，无需点按钮。
  • 显示无效点击：在游戏设置中勾选后，回放用灰点标出无效点击（数字格/已标雷格/空格上的左键、数字格/空格上的右键、非数字格上的双击）；点击数、IOE 等指标直接取自录像内的真实采样，与实时对局完全一致。

竞速与个性化

  • 四种难度：初级 9×9/10 · 竞速初级 8×8/10 · 中级 16×16/40 · 高级 16×30/99，各自独立排行榜。
  • 皮肤、数字配色、数字字体多方案；空格/鼠标中键随时重开；可选自动重开（按完成率阈值）。

防作弊体系

  • 计时基于真实流逝时间并交叉校验帧速，改系统时间、变速软件均会识别。
  • 主脚本完整性采用双保险：SHA-256 指纹自举校验 + 构建时 RSA-2048 数字签名（公钥内嵌、私钥不随文件发布），难度表加密存储——改动任何一行代码而未经重新签名，游戏都无法启动；没有私钥也无法伪造合法签名。
  • 关键状态属性（作弊标记、播放态、导出权限）以 defineProperty 守卫做即时拦截，配合定时巡检兜底；整个类包在闭包中并冻结原型，外部拿不到实例。
  • 页面加载时执行一次双盲板校验：两块仅未揭示区域不同的虚拟棋盘喂给 3BV 算式，输出必须一致——从语义上证明"当前3BV"只从已揭示部分推导、绝不偷看未揭示区域；仅加载时运行，对局过程零开销。

六、北京特色

  • 京味儿命名「扫雷一下」——就像"瞅一眼""来一把"，轻松随意，是北京人说话的劲儿。
  • 地铁配色数字配色方案可切换为「北京地铁1-8号线」与「北京地铁11-18号线」，1~8 逐个采用官方线路色（1号线 #A4343A、2号线 #004B87、5号线 #AA0061、13号线 #F4DA40……），看数字像看地铁图。
  • 苏州码子数字字体方案另有「苏州码子」：〡〢〣〤〥〦〧〨 一一对应 1~8。这种老式商用记数符号曾用于京张铁路（詹天佑主持修建）的里程标，如今搬到扫雷盘面上，是北京铁路记忆的数字化彩蛋。
  • 北京作者创作者张帆，土生土长的北京独立开发者，一人完成设计、编码与测试。
